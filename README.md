## 🚀 Recent AI engineering projects

These projects explore how to combine AI capabilities with **reliable, testable software engineering**, rather than treating AI-generated output as inherently correct.

### 1. [Enterprise RAG — Document Intelligence](https://github.com/hidayatarg/enterprise-rag)

A document question-answering application built with **React, TypeScript, Python/FastAPI, PostgreSQL + pgvector, and Ollama**.

- Document ingestion, chunking, embeddings, and semantic retrieval
- Grounded answers with document citations and evidence validation
- Safeguards for irrelevant results, unsupported answers, and prompt-injection attempts
- Retrieval evaluation and regression-oriented testing workflows

**Focus:** Retrieval quality, citation faithfulness, abstention, and testable LLM integration.

### 2. [AI-Driven .NET 10 Todo Backend Template](https://github.com/hidayatarg/ai-dotnet-todo-template)

A reusable **.NET 10 backend template** demonstrating AI-assisted development with a four-agent team and automated engineering standards.

- **Four defined agents:** API/service engineer, repository/data engineer, tester, and code reviewer
- Agent definitions for **Claude Code, Cursor, and OpenAI Codex**, with checks against configuration drift
- Layered backend architecture, PostgreSQL/EF Core, API validation, and testing
- Quality gates covering formatting, builds, static analysis, tests, and coverage thresholds

**Focus:** Making AI-assisted software development repeatable, reviewable, and quality-driven.

### 3. Language-Agnostic AI Engineering Prompt Kit

A reusable, **technology-independent starting point** for projects developed with AI coding agents.

- Start with infrastructure, instructions, and engineering conventions before application code
- Reuse the development approach across different programming languages and technology stacks
- Support workflows across **Cursor, Claude Code, and OpenAI Codex**
- Establish a shared foundation for agent responsibilities, code quality, and implementation guidance

**Focus:** Reducing tool lock-in and keeping engineering conventions consistent across AI coding tools.
